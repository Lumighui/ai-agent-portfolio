# 卢朝鑫｜个人 AI Agent 使用档案

React + Vite + GSAP 个人网站，展示 Codex 与豆包的真实使用情况和成果。

## 本地开发

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build
```

构建结果输出到 `dist/`。
